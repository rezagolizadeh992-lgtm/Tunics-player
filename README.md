# 🎵 پخش‌کننده موزیک

یک پخش‌کننده‌ی موزیک تحت وب، سبک، بدون نیاز به نصب هیچ برنامه‌ای، با ظاهری الهام‌گرفته از دستگاه‌های صوتی آنالوگ (رنگ برنز و مسی) و مجموعه‌ای از قابلیت‌های صوتی واقعی که معمولاً فقط در اپلیکیشن‌های حرفه‌ای پیدا می‌شوند.

این پروژه به‌صورت یک **صفحه‌ی وب مستقل (Single Page App)** ساخته شده و همچنین به شکل **PWA (Progressive Web App)** قابل نصب روی گوشی است.

---

## ✨ قابلیت‌ها

### پخش و ناوبری
- ▶️ پخش / توقف
- ⏪ پرش ۵ ثانیه‌ای به عقب
- ⏩ پرش ۵ ثانیه‌ای به جلو
- ⏮ پخش فایل قبلی / ⏭ پخش فایل بعدی (پشتیبانی از پلی‌لیست چند فایلی)
- نوار پیشرفت پخش، قابل کنترل با کلیک یا صفحه‌کلید

### کنترل صدا
- 🎚 **تغییر سرعت پخش** (۰٫۵× تا ۲×) — بدون تغییر زیر و بمی صدا (Pitch مستقل از سرعت)
- 🔊 **بیس** — تقویت یا کاهش فرکانس‌های پایین صدا
- 🔊 **زیر (تربل)** — تقویت یا کاهش فرکانس‌های بالای صدا

### حذف صدای خواننده (وکال ریموور)
ترکیبی از سه تکنیک برای نتیجه‌ی تمیزتر و پرصداتر:
1. **حذف کانال مرکزی** (Center-Channel Cancellation) — تفاضل کانال چپ و راست، که هر صدای دقیقاً مرکزی (معمولاً خواننده) را حذف می‌کند
2. **حفظ بیس** — چون تکنیک بالا بیس/درام مرکزی را هم حذف می‌کند، فرکانس‌های پایین به‌طور جداگانه از میکس اصلی برداشته و دوباره اضافه می‌شوند تا نتیجه تو‌خالی و نازک نشود
3. **فیلتر میراکننده‌ی فرمنت صدا** — چند فیلتر Notch روی فرکانس‌های رایج صدای انسان (تقریباً ۲۸۰ تا ۳۶۰۰ هرتز) باقی‌مانده‌ی صدای خواننده‌ای که تکنیک اول به‌طور کامل حذف نکرده را کم‌رنگ‌تر می‌کند

یک اسلایدر شدت (۰ تا ۱۰۰٪) میزان این افکت را کنترل می‌کند.

> ⚠️ **صادقانه بگم:** این روش کاملاً مبتنی بر پردازش سیگنال کلاسیک است، نه هوش مصنوعی. جداسازی واقعی و حرفه‌ای صدا (مثل استودیوهای واقعی) با ابزارهایی مثل Spleeter یا LALAL.AI انجام می‌شود که از یک مدل یادگیری عمیق برای تشخیص و جداسازی صدا استفاده می‌کنند — کاری که در مرورگر و با پردازش لحظه‌ای ممکن نیست. نسخه‌ی فعلی نتیجه‌ی به‌مراتب بهتر و پرصداتری نسبت به حذف ساده‌ی کانال مرکزی می‌دهد، ولی جایگزین کامل جداسازی مبتنی بر هوش مصنوعی نیست. همچنین فقط روی فایل استریو و آهنگ‌هایی که خواننده وسط میکس باشد جواب می‌دهد.

### شبیه‌سازی فضای صدا (Room Simulation)
با استفاده از **Convolution Reverb** واقعی (نه فیلتر ساده)، صدا را طوری پردازش می‌کند که انگار در یک فضای فیزیکی واقعی پخش می‌شود:

| فضا | حس صدا |
|---|---|
| خشک (بدون افکت) | صدای اصلی، بدون هیچ پردازشی |
| 🚿 حمام | پژواک کوتاه و فلزی |
| 🏠 اتاق ۵۰ متری | پژواک متعادل یک فضای بسته‌ی معمولی |
| 🏛 سالن | پژواک بلندتر و پرحجم‌تر |
| 🎤 سالن کنسرت | پژواک بلند، غنی و پرصدا — حس واقعی یک اجرای زنده |

شدت این افکت با یک اسلایدر جداگانه قابل تنظیم است (۰ تا ۱۵۰٪).

### ضبط خروجی با افکت‌ها
یک دکمه‌ی «ضبط با افکت‌های فعلی» وجود دارد: با فشردنش، آهنگ از ابتدا با همان تنظیمات لحظه‌ای (سرعت، بیس، زیر، فضای صدا، وکال ریموور) پخش و همزمان ضبط می‌شود؛ با تمام شدن آهنگ، ضبط خودش خودکار متوقف می‌شود (یا می‌توانید هر وقت خواستید دستی متوقفش کنید).

بعد از پایان ضبط:
1. برنامه فایل ضبط‌شده را در پس‌زمینه به **MP3** تبدیل می‌کند (با کتابخانه‌ی متن‌باز [lamejs](https://github.com/zhuker/lamejs)، بارگذاری‌شده فقط در همین لحظه، نه در بارگذاری اولیه‌ی صفحه)
2. درصد پیشرفت ساخت MP3 به‌صورت زنده روی صفحه و برای صفحه‌خوان (هر ۲۰٪) اعلام می‌شود
3. یک دکمه‌ی «دانلود» ظاهر می‌شود (بدون اشاره به رنگ، برای دسترسی‌پذیری کامل) که با لمس آن، فایل در پوشه‌ی Download ذخیره می‌شود

اگر تبدیل به MP3 به هر دلیلی (مثلاً نبود اینترنت) ممکن نباشد، خود فایل ضبط‌شده‌ی اصلی (فرمت WebM/Opus یا مشابه، کاملاً قابل پخش) به‌جایش ذخیره می‌شود — یعنی دکمه هیچ‌وقت بدون نتیجه نمی‌ماند.

> این روش عمداً ساده نگه داشته شده: به‌جای رندر آفلاین سنگین، مستقیماً از API بومی ضبط مرورگر (`MediaRecorder`) استفاده می‌کند. تنها تفاوتش این است که ضبط هم‌زمان با پخش انجام می‌شود، یعنی برای یک آهنگ ۳ دقیقه‌ای، ۳ دقیقه طول می‌کشد.

### دسترسی‌پذیری (Accessibility)
این پروژه با در نظر گرفتن کاربران نابینا و کم‌بینا ساخته شده:
- برچسب صوتی (`aria-label`) دقیق و فارسی روی تمام دکمه‌ها و اسلایدرها
- اعلام رویدادها به صفحه‌خوان (شروع پخش، توقف، تغییر فضای صدا، بارگذاری فایل، پیشرفت ضبط و ...) بدون شلوغی بصری
- هیچ راهنمایی بر پایه‌ی رنگ نیست (مثلاً «دکمه‌ی دانلود» گفته می‌شود، نه «دکمه‌ی سبز»)
- نوار پیشرفت پخش کاملاً با صفحه‌کلید قابل کنترل (کلیدهای جهت‌نما، Home، End)
- تمام کنترل‌ها با Tab قابل دسترسی و دارای نشانگر فوکوس واضح

### نصب روی گوشی (PWA)
- قابل «Add to Home Screen» از طریق کروم، بدون نیاز به فروشگاه اپلیکیشن
- کارکرد آفلاین برای پوسته‌ی برنامه (Service Worker)
- قابل تبدیل به فایل APK واقعی با ابزار رایگان [PWABuilder](https://www.pwabuilder.com)

---

## 📁 فایل‌های پروژه

| فایل | توضیح |
|---|---|
| `index.html` | خود برنامه |
| `manifest.json` | تنظیمات نصب PWA (نام، آیکون) |
| `sw.js` | Service Worker — برای کارکرد آفلاین |
| `icon-192.png` / `icon-512.png` | آیکون برنامه |

> 💡 یک نسخه‌ی جایگزین و تک‌فایلی هم موجوده که `manifest.json` و آیکون‌ها داخل خود `index.html` جاسازی شده‌اند (فقط `index.html` + `sw.js` لازمه). برای اطمینان کامل از نصب، همین نسخه‌ی چندفایلی استاندارد توصیه می‌شود.

## 🚀 راه‌اندازی

### اجرای مستقیم
فایل `index.html` را در هر مرورگر مدرنی باز کنید. نیازی به سرور یا نصب چیزی نیست.

### اجرا به‌صورت PWA (نصب روی گوشی)
1. تمام فایل‌های این پوشه (`index.html`، `manifest.json`، `sw.js`، آیکون‌ها) را روی یک هاست ساده و رایگان قرار دهید (مثل GitHub Pages یا Netlify)
2. آدرس را در کروم گوشی باز کنید
3. گزینه‌ی «افزودن به صفحه اصلی» را انتخاب کنید

### تبدیل به APK
با استفاده از [pwabuilder.com](https://www.pwabuilder.com) و دادن آدرس سایت هاست‌شده، یک فایل APK واقعی و نصب‌شدنی دریافت کنید.

## 🛠 ساختار فنی

| بخش | توضیح |
|---|---|
| رابط کاربری | HTML + CSS خالص، بدون فریم‌ورک |
| پردازش صدا | Web Audio API (BiquadFilter برای بیس/تربل، ConvolverNode برای فضای صدا، فیلترهای Notch و کانال مرکزی برای وکال ریموور، DynamicsCompressor + Limiter برای جلوگیری از خش‌دار شدن صدا) |
| ضبط و خروجی | `MediaRecorder` بومی مرورگر برای ضبط، [lamejs](https://github.com/zhuker/lamejs) (بارگذاری تنبل از cdnjs، فقط هنگام نیاز) برای تبدیل به MP3 |
| پایداری پخش | `latencyHint: 'playback'` روی AudioContext (بافر بزرگ‌تر، مقاوم‌تر در برابر قطع‌وصل روی هدفون/بلوتوث) + خروجی استریوی صریح (۲ کاناله) برای استفاده‌ی درست از هر دو بلندگوی گوشی |
| نصب‌پذیری | Web App Manifest + Service Worker |
| زبان رابط | فارسی، راست‌به‌چپ (RTL) |

هیچ فایل صوتی خارجی (Impulse Response) استفاده نشده؛ پژواک هر فضا به‌صورت الگوریتمی و در لحظه تولید می‌شود.
